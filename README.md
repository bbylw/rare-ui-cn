Rare UI 是一个基于 Next.js、Tailwind CSS 和 TypeScript 构建的 shadcn 注册表。每个组件都用 Motion 做了动画，遵循 `prefers-reduced-motion`，并且能直接安装到你的代码库中。代码归你所有：没有需要依赖的包，任何样式都可以自定义。

## 快速开始

用 shadcn CLI 安装任意组件：

```bash
npx shadcn@latest add swamimalode07/rare-ui/{component-name}
```

例如：

```bash
npx shadcn@latest add swamimalode07/rare-ui/fluid-orb
```

在 [rareui.com/components](https://rareui.com/components) 浏览每一个组件，包含实时预览与属性说明。

## 本地运行

```bash
git clone https://github.com/swamimalode07/rare-ui.git
cd rare-ui
npm install
npm run dev
```

组件位于 `components/ui`。修改组件或 `registry.json` 后，用 `npm run registry:build` 重新构建注册表输出。
